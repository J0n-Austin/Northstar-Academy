Northstar Academy

interactive

The core loop, live: onboarding → a portal with a ticket queue and activity feed → a simulated in-browser terminal (tab-completion, a file editor) where you practice commands → tasks check themselves → open a pull request, get a mentor review, and merge. Fifteen labs playable across six stages: fundamentals, scripting, C, service triage, network diagnostics, sockets & protocols, detection engineering, Linux and Windows internals, secure coding, debugging, code review, incident analysis, an ambiguous open ticket, and an integrated on-call capstone. Plus a curriculum map, a company wiki, and an evidence-linked competency transcript. Nothing to install. Source + tests in app/.
