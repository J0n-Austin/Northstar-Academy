# Hints — Task 1

**Hint 1 (concept).** You need lines that match *two* conditions. You can filter once,
then filter the result again by piping one command into another.

**Hint 2 (tactic).** `grep` can search several files at once. The `-i` flag makes a match
case-insensitive. The `-w` flag matches a whole word. To count matching lines, look at
`grep -c` or pipe into `wc -l`.

**Hint 3 (almost there).** Filter all the logs down to ERROR lines, then count how many
of those mention timeout:

```bash
grep -h -w ERROR scenario/logs/*.log | grep -i -c timeout
```
