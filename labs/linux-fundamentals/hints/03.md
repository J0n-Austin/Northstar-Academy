# Hints — Task 3

**Hint 1 (concept).** `jq` walks a JSON structure. You want to reach into the
`services` array, keep only the elements whose `state` equals `"degraded"`, and print
their `name`.

**Hint 2 (tactic).** `.services[]` streams each element of the array. `select(...)`
keeps only elements matching a condition. `-r` prints raw strings (no quotes). Then
pipe the names through `sort`.

**Hint 3 (almost there).**

```bash
jq -r '.services[] | select(.state == "degraded") | .name' \
  scenario/service/status.json | sort > answers/03.txt
```
