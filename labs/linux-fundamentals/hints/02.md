# Hints — Task 2

**Hint 1 (concept).** This is a "count how many of each, then rank" problem. The classic
shape is: isolate the thing you're counting → `sort` → `uniq -c` → `sort` again by count.

**Hint 2 (tactic).** `grep -oE 'code=E[0-9]+'` prints only the matching `code=Exxx`
part of each line. Strip the `code=` prefix with `sed 's/code=//'` or `cut -d= -f2`.
`uniq -c` needs its input sorted first. `sort -rn` sorts by number, high to low.

**Hint 3 (almost there).** `uniq -c` prints `COUNT CODE`, but the task wants
`CODE COUNT`, so swap the columns at the end:

```bash
grep -w ERROR scenario/logs/app.log \
  | grep -oE 'code=E[0-9]+' | sed 's/code=//' \
  | sort | uniq -c | sort -rn | head -3 \
  | awk '{print $2, $1}' > answers/02.txt
```
