# Hints — Task 4

**Hint 1 (concept).** Linux permissions have three groups: owner, group, others — each
with read (r), write (w), execute (x). "Only the owner can read and write" means the
group and others get nothing.

**Hint 2 (tactic).** Look at the current bits with `ls -l scenario/secrets/service.key`.
`chmod` sets permissions. In octal, each digit is owner / group / others, and
read+write = 6, no access = 0.

**Hint 3 (almost there).**

```bash
chmod 600 scenario/secrets/service.key
ls -l scenario/secrets/service.key   # should show -rw-------
```
