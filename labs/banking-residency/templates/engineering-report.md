# Engineering submission — NS-C___

## Problem and reproduction
What happened? What was expected? Exact reproduction with synthetic data.

## Root cause and design decision
Which line or component caused the issue? Why did you choose this fix?

## Tests and evidence
Run command, date, observed result, and commit hash/PR URL (when available).
Do not claim passing tests if you did not run them.

## Security / privacy impact
What could the defect expose or damage? What threat model still remains?

## Release and rollback
What would you monitor after release? How could you safely revert?

## Reviewer questions
What alternative approach did you consider? What tradeoff did you accept?
