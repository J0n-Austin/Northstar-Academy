STAGE 1 · REAL EXECUTION

Build and debug with real tools

The browser academy uses simulated systems and is good for guided practice. These labs run in an actual Linux shell with GCC, POSIX APIs and a real localhost network. GitHub Pages hosts only instructions; open the repository in GitHub Codespaces or use Ubuntu locally.

Start a workspace

From your GitHub repository, select Code → Codespaces → Create codespace on main. Wait for the devcontainer setup to complete. Open its terminal at the repository root.

npm run check
cd labs/native-c-engineering
bash run-checks.sh

The first native C lab deliberately ships with defects; a failing learner check is expected until the student fixes it. Repository-level npm run check validates the challenge's intended initial state without pretending the starter solution is correct.
