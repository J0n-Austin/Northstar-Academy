# Hints — Unit 1

**Hint 1 (concept).** Every fact you need is already written down — in the log file or
the config file. You're reading, not running anything that changes state.

**Hint 2 (tactic).** `grep -c PATTERN file` counts matching lines. To find the *most
recent* error, the log is in time order, so the last error line is at the bottom
(`grep ERROR … | tail -1`). Config values are `key = value` lines in
`etc/telemetryd.conf`.

**Hint 3 (almost there).**
```bash
grep -c "start failed" var/log/telemetryd.log        # failed_starts
grep ERROR var/log/telemetryd.log | tail -1          # read the code off this line
grep '^endpoint' etc/telemetryd.conf                 # endpoint
```
Write the three values into `answers/01.txt` as `key = value` lines.
