# Hints — Unit 2

**Hint 1 (concept).** The service tells you exactly what's wrong when it fails — one
problem at a time. Fix what it reports, run it again, and it will either pass or report
the next problem.

**Hint 2 (tactic).** Run `bash bin/telemetryd --check` and read the `E_...` line.
`E_CONF_*` means a value in `etc/telemetryd.conf` is wrong. `E_PERM` means a file's
permissions are too open — check with `ls -l` and fix with `chmod`. An interval of `0`
is not a positive number.

**Hint 3 (almost there).**
```bash
# fix the interval in etc/telemetryd.conf (any positive integer, e.g. 15)
# then tighten the key file so only the owner can read/write it:
chmod 600 etc/telemetryd.key
bash bin/telemetryd --check
```
